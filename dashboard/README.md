# Power BI dashboard

`L&D dashboard.pbix` contains the Learning & Development dashboard showcased in this repository and on the Virtavis portfolio.

Verified headline metrics:

- 25 participants
- 22 completed trainings
- 88.0% completion rate
- 83.8 average score for completed training
- 124 completed training hours

The model uses an Excel-sourced `Training_data` table and DAX measures documented in [../docs/dax_measures.md](../docs/dax_measures.md).
